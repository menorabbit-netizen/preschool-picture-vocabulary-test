# 취학 전 아동 그림어휘력 검사

취학 전 아동의 기초 어휘력을 간단히 확인하기 위한 10문항 그림 선택형 웹앱입니다.

## 구성

- 동물 5문항: 강아지, 고양이, 새, 물고기, 말
- 일상용품 5문항: 컵, 의자, 숟가락, 칫솔, 신발
- 문항별 4개 그림 선택지: 정답 1개, 오답 3개
- 실시간 대시보드: 총점, 범주별 점수, 진행률
- 결과 대시보드: 총점, 범주별 점수, 범주별 및 전체 평균 반응 시간
- 문항별 반응 기록을 UTF-8 BOM 형식 CSV로 내보내기

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. 필요하면 아동 식별자를 입력하고 **검사 시작**을 누릅니다.
3. 검사자가 화면의 목표 낱말을 읽어 주고 아동이 선택한 그림을 클릭합니다.
4. 10문항이 끝나면 결과를 확인하고 **CSV 내보내기**를 누릅니다.

## 그림 출처 및 라이선스

그림은 [OpenSymbols](https://opensymbols.org/)에서 제공하는 다음 공개 라이선스 심볼의 원격 이미지 주소를 사용합니다.

- ARASAAC: 강아지, 고양이, 새, 말, 숟가락, 칫솔, 신발 (CC BY-NC-SA)
- Twemoji: 물고기 (CC BY)
- The Noun Project: 컵 (CC BY-SA)
- Mulberry Symbols: 의자 (CC BY-SA)

각 그림의 원저작자와 세부 라이선스는 OpenSymbols에서 확인해야 합니다. ARASAAC의 비상업 조건을 포함하므로, 실제 배포 또는 상업적 사용 전에는 해당 라이선스의 적합성을 검토하세요.
